# Coupon Campaign Revenue Prediction 

A machine learning project that predicts the **revenue generated by a promotional coupon campaign** before or during its run, using campaign configuration, branch history, and behavioral features. Built as an individual, end-to-end ML project — from messy raw data to a validated, tuned model.

##  Problem Statement

Businesses run many coupon campaigns with different reward structures, budgets, and target branches, but it's hard to know in advance which campaign setup will actually drive revenue. This project builds a model that predicts campaign revenue from its configuration and historical branch behavior, to support better campaign planning.

##  Objective

Train and compare regression models to predict `CAMPAIGN_REVENUE_SAR` for a coupon campaign, and identify which features drive revenue the most.

##  Project Workflow

1. **EDA** — inspected a dataset of 20,400 campaigns × 17 columns; checked structure, missing values, and duplicates (400 duplicate rows found).
2. **Data Preprocessing**
   - Parsed and validated date columns (`START_DATE`, `END_DATE`).
   - Cleaned inconsistent category labels (e.g. unifying `"percent"` → `"percentage"`).
   - Removed invalid/sentinel values (negative revenue, a `99999999` placeholder, end dates before start dates).
   - Label-encoded the reward type; imputed missing values (mode for categorical, appropriate strategy for numeric).
   - Investigated outliers with the IQR rule (~5.4% of campaigns flagged) — kept them, since they likely represent genuinely high-performing campaigns rather than data errors.
3. **Feature Engineering** — derived `DURATION_DAYS` and seasonality-related features; selected a feature set combining reward configuration, branch historical behavior, and campaign structure.
4. **Modeling** — trained and compared four models:
   - Naive baseline (predicts the mean revenue)
   - Linear Regression (with feature scaling)
   - Random Forest Regressor
   - XGBoost Regressor
5. **Hyperparameter Tuning** — `RandomizedSearchCV` for both Random Forest and XGBoost (search space reduced after an initial too-large grid caused runtime issues).
6. **Evaluation & Diagnostics** — MAE, RMSE, R² comparison; actual-vs-predicted scatter plot, residual/error distribution analysis, and feature importance ranking.

##  Results

| Model | MAE | RMSE | R² |
|---|---|---|---|
| Naive Baseline | 23,167.7 | 32,806.2 | ~0.00 |
| Linear Regression | 14,514.1 | 22,489.0 | 0.530 |
| Random Forest (Tuned) | 7,862.2 | 13,621.6 | 0.828 |
| **XGBoost (Tuned)** | **6,325.8** | **11,193.4** | **0.884** |

The tuned **XGBoost** model performed best, explaining **88.3%** of the variance in campaign revenue. Feature importance shows that **historical branch activity** (prior orders, average order value, branch order volume) is a stronger revenue driver than the reward configuration itself — meaning past branch/customer behavior matters more than how the coupon is structured.

##  Limitations & Future Work

- The residual analysis shows prediction error variance increases at higher predicted revenue values (a mild "funnel" pattern), suggesting the model is less reliable for very high-revenue campaigns.
- No external factors (e.g. seasonality events, competitor campaigns, macroeconomic conditions) are included — adding them could further improve accuracy.
